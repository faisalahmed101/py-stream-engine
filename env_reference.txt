# ============================================================
# Kubernetes deploy korar shomoy nicher note gulo dekho -- ei
# .env file er kono line change kora hoyni, shudhu reference:
# ============================================================
#
# 1) ConfigMap vs Secret split:
#    - ConfigMap e rakho (non-sensitive): RESTART_BACKOFF_BASE,
#      RESTART_BACKOFF_MAX, DEBUG, STALL_TIMEOUT_SECONDS,
#      STALL_WATCHDOG_ENABLED, NMS_DIR, RTMP_URL, STREAM_NAME,
#      STREAM_PLAYLIST, HEALTH_PORT
#    - Secret e rakho (sensitive -- stream key thake): PUSH_DESTINATIONS
#      (etar moddhe YouTube/Facebook er live stream key ache -- eta
#      leak hole jekeu tomar channel e push korte parbe)
#    Deployment manifest e Secret ke `envFrom.secretRef` r ConfigMap ke
#    `envFrom.configMapRef` diye inject korle, main.py/worker/relay er
#    load_env_file() nijei shei value gulo respect korbe (os.environ e
#    already thakle .env file overwrite kore na), tai .env file container
#    image e na thakleo (recommended -- production e .env baked-in na
#    rakhai bhalo) code kono change chara i cholbe.
#
# 2) HEALTH_PORT (notun, main.py e add kora hoyeche): main.py ekhon
#    /healthz (liveness) r /readyz (readiness) serve kore ei port e
#    (default 8081). Deployment manifest e containerPort + livenessProbe/
#    readinessProbe eর shathe eta match korte hobe.
#
# 3) File logging (RUN_ALL_LOG / WORKER_LOG / PUSH_RELAY_LOG): ekhon
#    DEFAULT E OFF -- kichu set na korleo console/stdout-only logging
#    hobe (k8s log collector shetai tule nebe). File-e-o log rakhte
#    chaile (e.g. local dev e) explicitly filename set koro, e.g.:
#    RUN_ALL_LOG=run_all.log
#
# 4) replicas: 1 rakho Deployment e -- eta horizontally scale kora
#    jaবে na (ekta Pod = ekta stream pipeline).
#
# 5) terminationGracePeriodSeconds: 30+ rakho -- RESTART_BACKOFF_MAX
#    (60s) r ffmpeg/node graceful shutdown shomoy dhorle SIGTERM er por
#    shomoy lagte pare.
