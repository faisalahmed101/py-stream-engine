# ============================================================
# RTMP_URL ekhon ekta BASE URL -- STREAM_NAME ar lagbe na.
# Trailing '/' porjonto rakho, kono stream key/naam add koro na -- actual
# push (stream_worker_stdin.py) r pull (push_relay.py) URL nijeই STREAM_ID
# jog kore banano hoy: base + '/' + STREAM_ID.
#   e.g. RTMP_URL=rtmp://localhost:1935/live/ + STREAM_ID=abc-123
#        -> actual URL: rtmp://localhost:1935/live/abc-123
# ============================================================
RTMP_URL=rtmp://localhost:1935/live/

# ============================================================
# STREAM_ID -- public.streams.id (uuid). Ei ekta value:
#   1) push/pull URL-er path/stream-key hisebe use hoy (upore dekho),
#   2) log line e "[stream=...]" hisebe bosbe,
#   3) stream_worker_stdin.py: STREAM_ID -> streams.playlist_id ->
#      playlist_items (sort_order onujayi) -- video playlist load korar
#      jonno Supabase e query hoy,
#   4) push_relay.py: STREAM_ID -> stream_destinations rows -- proti row
#      ekta destination (platform/rtmp_url/stream_key), r proti destination
#      er jonno ALADA ffmpeg process spawn hoy.
# Supabase unreachable/misconfigured hole (network down, playlist_id null,
# playlist_items/stream_destinations khali) stream/relay shuru hobe na --
# fixed interval e (15s) infinite retry cholbe jotokkhon na valid data
# pawa jay.
# ============================================================
STREAM_ID=<uuid -- public.streams.id>
SUPABASE_URL=https://<your-project-ref>.supabase.co
# service_role key -- RLS bypass kore, tai eta SHUDHU server-side/backend e
# (ei .env file, k8s Secret) rakho, kokhono client/browser/frontend code e na.
SUPABASE_SERVICE_ROLE_KEY=<your-supabase-service-role-key>

# ============================================================
# Kubernetes deploy korar shomoy nicher note gulo dekho -- ei
# .env file er kono line change kora hoyni, shudhu reference:
# ============================================================
#
# 1) ConfigMap vs Secret split:
#    - ConfigMap e rakho (non-sensitive): RESTART_BACKOFF_BASE,
#      RESTART_BACKOFF_MAX, DEBUG, STALL_TIMEOUT_SECONDS,
#      STALL_WATCHDOG_ENABLED, NMS_DIR, RTMP_URL, STREAM_ID, SUPABASE_URL,
#      HEALTH_PORT
#    - Secret e rakho (sensitive -- DB access thake):
#      SUPABASE_SERVICE_ROLE_KEY (RLS bypass kore -- leak hole je-kono
#      streams/playlist/stream_destinations row poRte parbe, stream key-o
#      shoho)
#    Deployment manifest e Secret ke `envFrom.secretRef` r ConfigMap ke
#    `envFrom.configMapRef` diye inject korle, main.py/worker/relay er
#    load_env_file() nijei shei value gulo respect korbe (os.environ e
#    already thakle .env file overwrite kore na), tai .env file container
#    image e na thakleo (recommended -- production e .env baked-in na
#    rakhai bhalo) code kono change chara i cholbe.
#
# 2) HEALTH_PORT (main.py e ache): main.py ekhon /healthz (liveness) r
#    /readyz (readiness) serve kore ei port e (default 8081). Deployment
#    manifest e containerPort + livenessProbe/readinessProbe eর shathe
#    eta match korte hobe.
#
# 3) Logging shudhu console/stdout e hoy (kono file logging nai) -- k8s
#    log collector (Fluent Bit/Loki/CloudWatch etc) shetai tule nebe.
#
# 4) replicas: 1 rakho Deployment e -- eta horizontally scale kora jaবে
#    na (ekta Pod = ekta stream pipeline).
#
# 5) terminationGracePeriodSeconds: 30+ rakho -- RESTART_BACKOFF_MAX
#    (60s) r ffmpeg/node graceful shutdown shomoy dhorle SIGTERM er por
#    shomoy lagte pare.
